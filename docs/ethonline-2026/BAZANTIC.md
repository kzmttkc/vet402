## 1. Takeshi 手番（5分）

1. **https://bazantic.com/login** を開く
2. **GitHub でサインアップ**を推奨（賞の要件に「bazantic のユーザー名——**email か GitHub handle** を
   提出物に書け」とあり、**GitHub なら帰属が一意**になる。提出リポ `kzmttkc/vet402` の持ち主と一致する）
   - GitHub 連携を避けたい場合は **Email**（コードが届く方式）でも要件を満たす
   - **パスワードや届いたコードをチャットに貼らないでください。** 私に要るのは
     「GitHub で作った」または「メールで作った」という**方式**と、**公開して構わない handle** だけ
3. ログイン後の画面で、次のどれが見えるか**スクショを1枚**ください
   - Gateway を作る導線（"Create Gateway" / "Add API" 等）が**すぐ使える**のか
   - **Request Beta Access** や **プロバイダ申請**を先に通す必要があるのか
4. ベータ申請が要るなら、その場で申請してください（内容は私が用意します——スクショをもらってから）

## 2. そのあと私がやること（会期中・9/8 目安）

- **x402/MPP Gateway** を vet402 の公開APIに対して設定する
- **Recipe** を書く: 「エージェントが x402 の 402 に出会ったとき、**署名する前に** `/decision` を引き、
  ALLOW 以外なら払わない。判定には facts（L0/L1/L2）と証拠URLが付く」
- **A/B の実証**（賞の中核・同じモデル・同じプロンプト・同じ設定で2回）
  - **A: 生のAPI情報だけ** → エージェントは測っていない相手に払ってしまう
  - **B: Recipe つき** → 署名前に止まり、理由コードを出す
  - 差分を**入力と結果ごと**提出物に載せ、動画で歩く
- この A/B は **P1（The Graph）と P2（World）のデモ材料としても最強**——仕組みの説明ではなく
  「使わなければ払ってしまう / 使えば止まる」という**価値の実演**になる。1本作れば3枠に効く
