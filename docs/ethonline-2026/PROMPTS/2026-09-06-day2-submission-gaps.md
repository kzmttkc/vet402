## この日の設計（A/B と Bazantic の発注に書いた要求）

- A/B の条件 B は、bazantic.com で作った Recipe にする。MCP を実際に経路へ入れる（Streamable HTTP の 3 手だけを自前で実装し、SDK を足さない）
  - 反映: `34c6b56`
- テストは状態を固定しない。「`liveReady` は false」のような表明は、改善した時点で赤くなる。規則を両方向で書く（blockers があれば false、無ければ true）
  - 反映: `8a18638`
- Bazantic のゲートウェイは $0 のルートでも 402 を返し、MCP の POST に載せた支払い署名は使われない。そこで、ツール結果が $0 の x402 402 だったときだけ署名して REST へ回す橋を置く。`amount !== "0"` なら署名せず止まる。A/B の両条件に同じように効き、署名回数と tx を生ログに残す
  - 反映: `bb7a721`
- 事前登録を守る。失敗した実行（401・402）は消さず、再実行は新しいタイムスタンプで残す。良い結果が出るまで回し直すことはしない
  - 反映: 09-07 の `b10f19b` が、402 で止まった実行（`093254Z`）と本走（`213134Z`）の生ログを並べて置いた
