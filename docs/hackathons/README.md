## Precedence

二つの順序を混ぜない。**制約が実行を縛り、実行は制約を書き換えない。**

**制約層（やってはいけないこと・境界）— 下の実行層すべてを拘束する**

1. [`STRATEGY.md`](./STRATEGY.md) — なぜこうするか。ルールの正本
2. [`GRANTS.md`](./GRANTS.md) — 同じ成果物を二度売らない・凍結中の動詞を助成に書かない・当日数字・中立

**実行層（いつ何をやるか）**

3. [`../ethonline-2026/WIN_EV.md`](../ethonline-2026/WIN_EV.md) — ETHOnline 受賞確度の上書き
4. [`../ethonline-2026/ROADMAP.md`](../ethonline-2026/ROADMAP.md) — ETHOnline 日次
5. [`2026-autumn-continuity.md`](./2026-autumn-continuity.md) — 3連戦の運用

つまり **GRANTS はハッカソンの日程を動かさない**（「グラントは列に割り込まない」= GRANTS.md §3 P0-1）が、
**WIN_EV / ROADMAP は STRATEGY・GRANTS の禁止事項を上書きできない**（二度売り・凍結動詞・古い数字・中立の放棄）。
2026-08-23 に順序の記載が二通り存在したため、この形で確定した。

Do not implement the next event’s verb before that event’s kickoff.
