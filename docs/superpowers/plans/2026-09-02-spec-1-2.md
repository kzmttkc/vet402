# vet402 製品定義書 v1.0（VET402-SPEC-1-2）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 製品定義書 v1.0 の P0/P1/P2 を、既存の観測所・スコア基盤の上に「同一IDで結合し直す」形で実装する。**§9.3 買い手モード（リクエスト前に `/decision?role=payer` を引き BLOCK/未検証なら送金しない配線）だけは 9/4 00:00 UTC まで入れない**（`AGENTS.md` フリーズ・`docs/ethonline-2026/SPEC_1_2_IMPACT.md` §0）。

**Architecture:** 新しい判定は「事実（L0–L2）→ 純関数の判定（版管理）→ 同じレスポンスに同居」の3層。IDは既存 uuid を主キーのまま残し、仕様§5の canonical ID を**列として追加して索引**する（既存URL・既存テストを壊さない）。決済索引は新テーブル `settlements` に「L1購入（test）」「POST /payments/x402（証明済み）」「オンチェーン索引（Base/Solana）」の3経路から書き、wash分類は純関数。失敗の公開は §10 の証拠規則を**述語関数**にして全公開面で共有する。

**Tech Stack:** Next.js 16 App Router / drizzle + neon-http（複文トランザクション不可・単文SQL原則）/ node:test（`tests/*.test.ts`、DB系は `*.pg.test.ts` を `--test-concurrency=1`）/ viem / @solana/web3.js / OpenAPI 3.1（`tests/openapi-*-parity.test.ts` が実装・SDK・MCP と突合）。

```ts
import { parseChallenge } from "./x402-payer";

type Dialect = "v1" | "v2" | "both" | "unpayable";

function parseEnvelope(headers: Headers, bodyText: string): { accepts: ChallengeAccept[] | null; dialect: Dialect } {
  const fromHeader = parseChallenge({ headers, bodyText: "" });
  let fromBody: ReturnType<typeof parseChallenge> = null;
  try { fromBody = parseChallenge({ headers: new Headers(), bodyText }); } catch { fromBody = null; }
  const h = fromHeader && fromHeader.accepts.length > 0 ? fromHeader.accepts : null;
  const b = fromBody && fromBody.accepts.length > 0 ? fromBody.accepts : null;
  if (h && b) return { accepts: h, dialect: "both" };
  if (h) return { accepts: h, dialect: "v2" };
  if (b) return { accepts: b, dialect: fromBody!.x402Version === 2 ? "v2" : "v1" };
  return { accepts: null, dialect: "unpayable" };
}
```

```ts
// anchors.ts に追加
export function missingDaysBetween(from: string, to: string, have: readonly string[]): string[] {
  const set = new Set(have);
  const out: string[] = [];
  for (let t = Date.parse(from + "T00:00:00Z"); t <= Date.parse(to + "T00:00:00Z"); t += 86_400_000) {
    const d = new Date(t).toISOString().slice(0, 10);
    if (!set.has(d)) out.push(d);
  }
  return out;
}

export function chainContinuity(newestFirst: readonly { day: string; rootHash: string; prevRoot: string | null }[]) {
  let linked = true;
  const gaps: string[] = [];
  for (let i = 0; i + 1 < newestFirst.length; i++) {
    if (newestFirst[i].prevRoot !== newestFirst[i + 1].rootHash) linked = false;
    gaps.push(...missingDaysBetween(newestFirst[i + 1].day, newestFirst[i].day, [newestFirst[i + 1].day, newestFirst[i].day]));
  }
  return { linked, contiguous: gaps.length === 0, gaps, intact: linked && gaps.length === 0 };
}

/** 直前の日（day-1）の root を取る。無ければ null（genesis 扱いにはしない——呼び手が先に埋める）。 */
async function prevDayRoot(db: Db, day: string): Promise<{ found: boolean; root: string | null }> {
  const prev = new Date(Date.parse(day + "T00:00:00Z") - 86_400_000).toISOString().slice(0, 10);
  const raw = await db.execute(sql`SELECT root_hash FROM ledger_anchors WHERE day = ${prev}`);
  const rows = (Array.isArray(raw) ? raw : (raw as { rows?: unknown[] }).rows ?? []) as { root_hash: string }[];
  if (rows.length === 0) {
    const anyBefore = await db.execute(sql`SELECT 1 FROM ledger_anchors WHERE day < ${day} LIMIT 1`);
    const has = ((Array.isArray(anyBefore) ? anyBefore : (anyBefore as { rows?: unknown[] }).rows ?? []) as unknown[]).length > 0;
    return { found: !has, root: null }; // 過去に1件も無ければ genesis で正しい
  }
  return { found: true, root: rows[0].root_hash };
}

/** from..to の欠けた日を古い順に埋めてから to を anchor する。 */
export async function anchorThrough(to: string, maxBackfillDays = 30): Promise<AnchorResult[]> {
  const db = getDb();
  if (!db) throw new Error("anchorThrough: DATABASE_URL is not configured");
  const raw = await db.execute(sql`SELECT day FROM ledger_anchors WHERE day <= ${to} ORDER BY day ASC`);
  const have = ((Array.isArray(raw) ? raw : (raw as { rows?: unknown[] }).rows ?? []) as { day: string }[]).map((r) => String(r.day));
  const from = have[0] ?? to;
  const missing = missingDaysBetween(from, to, have).slice(-maxBackfillDays);
  const out: AnchorResult[] = [];
  for (const d of missing) out.push(await anchorDay(d));
  if (!missing.includes(to)) out.push(await anchorDay(to));
  return out;
}
```
`anchorDay` 内の `prevRoot` 取得を `prevDayRoot` に置換し、`found === false` なら `throw new Error(\`anchorDay: ${day} の前日が未固定——anchorThrough で先に埋める\`)`。cron は `anchorDay(utcDay(-1))` → `anchorThrough(utcDay(-1))` に変更（穴が cron 1回の失敗で残らない）。`cli/verify-anchors.ts` の最終行を `chainContinuity(anchors)` の結果 JSON（`{ days, linked, contiguous, gaps, chainIntact: intact }`）に置換。

```ts
const sha = (s: string) => createHash("sha256").update(s, "utf8").digest("hex");
/** 署名・時刻など、測定対象から外す可変クエリ名（小文字比較）。宣言できないので undeclared として開示する。 */
export const VOLATILE_QUERY_KEYS = new Set(["sig", "signature", "ts", "timestamp", "nonce", "token", "apikey", "api_key", "key", "expires", "exp"]);

export function canonicalUrl(raw: string): { url: string; undeclaredQuery: string[] } | null {
  let u: URL;
  try { u = new URL(raw.trim()); } catch { return null; }
  if (u.protocol !== "https:") return null;
  const host = u.hostname.toLowerCase();
  const port = u.port && u.port !== "443" ? `:${u.port}` : "";
  let path = u.pathname.replace(/\/+$/, "");
  if (path === "") path = "/";
  const kept: [string, string][] = [];
  const undeclared: string[] = [];
  for (const [k, v] of u.searchParams) (VOLATILE_QUERY_KEYS.has(k.toLowerCase()) ? undeclared : kept).push(VOLATILE_QUERY_KEYS.has(k.toLowerCase()) ? k : [k, v] as never);
  kept.sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
  const qs = kept.map(([k, v]) => `${encodeURIComponent(k)}=${encodeURIComponent(v)}`).join("&");
  return { url: `https://${host}${port}${path === "/" ? "" : path}${qs ? `?${qs}` : ""}` || `https://${host}${port}`, undeclaredQuery: undeclared.sort() };
}

  const url = c ? c.url : rawUrl.trim();

}

}
```

```ts
// src/lib/settlements/wash.ts
import type { WashFlag } from "./types";
export type WashContext = {
  testWallets: ReadonlySet<string>;                 // payer_id の集合
  sameCluster: (payerId: string, payeeId: string) => boolean; // 同一 funder / 同一 8004 owner
  reverseWithinHours: (payerId: string, payeeId: string, at: Date, hours: number) => boolean;
};
export const CIRCULAR_WINDOW_HOURS = 24;
export function classifyWash(s: { payerId: string | null; payeeId: string | null; blockTime: Date | null }, ctx: WashContext): WashFlag {
  if (s.payerId && ctx.testWallets.has(s.payerId)) return "test";
  if (!s.payerId || !s.payeeId) return "none";
  if (s.payerId === s.payeeId) return "self_deal";
  if (ctx.sameCluster(s.payerId, s.payeeId)) return "self_deal";
  if (s.blockTime && ctx.reverseWithinHours(s.payerId, s.payeeId, s.blockTime, CIRCULAR_WINDOW_HOURS)) return "circular";
  return "none";
}
```

```ts
// src/lib/settlements/attribution.ts
import type { Attribution } from "./types";
export const ATTRIBUTION_WINDOW_MS = 15 * 60_000;
export function attribute(
  tx: { payee: string | null; amount: string | null; asset: string | null; chain: string; blockTime: Date | null },
  envelope: { payTo: string | null; amount: string | null; asset: string | null; network: string | null; observedAt: Date | null },
): Attribution {
  const same = (a: string | null, b: string | null) => !!a && !!b && a.toLowerCase() === b.toLowerCase();
  if (!same(tx.payee, envelope.payTo)) return "unmatched";
  if (envelope.network && tx.chain !== envelope.network) return "unmatched";
  const amountOk = same(tx.amount, envelope.amount) && same(tx.asset, envelope.asset);
  const timeOk = !!tx.blockTime && !!envelope.observedAt && Math.abs(tx.blockTime.getTime() - envelope.observedAt.getTime()) <= ATTRIBUTION_WINDOW_MS;
  return amountOk && timeOk ? "confirmed" : "probable";
}
```

```ts
// src/lib/resolve/classify.ts
export type QueryKind = "url" | "domain" | "address" | "tx" | "payee_id" | "unknown";
const EVM_ADDR = /^0x[0-9a-fA-F]{40}$/, EVM_TX = /^0x[0-9a-fA-F]{64}$/;
const B58 = /^[1-9A-HJ-NP-Za-km-z]+$/, DOMAIN = /^(?=.{1,253}$)([a-z0-9-]+\.)+[a-z]{2,}$/i;
export function classifyQuery(raw: string): { kind: QueryKind; value: string } {
  const q = raw.trim();
  if (/^https?:\/\//i.test(q)) return { kind: "url", value: q };
  if (/^(eip155:\d+|solana:[1-9A-HJ-NP-Za-km-z]{32,44}):/.test(q)) return { kind: "payee_id", value: q };
  if (EVM_TX.test(q)) return { kind: "tx", value: q.toLowerCase() };
  if (EVM_ADDR.test(q)) return { kind: "address", value: q.toLowerCase() };
  if (B58.test(q) && q.length >= 80 && q.length <= 90) return { kind: "tx", value: q };
  if (B58.test(q) && q.length >= 32 && q.length <= 44) return { kind: "address", value: q };
  if (DOMAIN.test(q)) return { kind: "domain", value: q.toLowerCase() };
  return { kind: "unknown", value: q };
}
```

```ts
// src/lib/decision/rules.ts
import type { SellerFacts, BuyerFacts, Dialect } from "./types";
export type Recommendation = "ALLOW" | "WARN" | "BLOCK";
export const DECISION_RULES_VERSION = "2026-09-02.1";
export const RETRY_BURST_BLOCK = 0.3;
export const THIN_HISTORY_MAX = 2;
export const NEW_PAYER_DAYS = 7;

export type PayerOptions = { callerDialect?: "v1" | "v2"; allowWithoutL1?: boolean; operatorBlacklist?: boolean; dataDepth?: "thin" | "moderate" | "rich" };
export function decidePayer(f: SellerFacts, o: PayerOptions): { recommendation: Recommendation; reason_codes: string[] } {
  const r: string[] = [];
  r.push(`l0_${f.l0.status}`);
  if (f.l1.n_attempts === 0) r.push("l1_not_attempted"); else if (f.l1.n_delivered >= 1) r.push("l1_delivered"); else r.push("l1_never_delivered");
  r.push(`l2_${f.l2.status}`);
  if (f.offer_stability === "drifting") r.push("offer_drifting");
  if (f.wash_dominated) r.push("wash_dominated");
  if (o.operatorBlacklist) r.push("operator_blacklist");
  if (o.dataDepth === "thin") r.push("data_thin");
  const dialectMismatch = !!o.callerDialect && !!f.l0.dialect && f.l0.dialect !== "both" && f.l0.dialect !== "unpayable" && f.l0.dialect !== o.callerDialect;
  if (dialectMismatch) r.push("dialect_mismatch");

  const block = f.l0.status !== "pass" || (f.l1.n_attempts >= 3 && f.l1.n_delivered === 0) || f.l2.status === "mismatch" || f.wash_dominated || !!o.operatorBlacklist;
  if (block) return { recommendation: "BLOCK", reason_codes: r };
  const warn = (f.l1.n_attempts === 0 && !o.allowWithoutL1) || f.l2.status === "undeclared" && false /* undeclared は単独では WARN にしない: 下で扱う */ || f.offer_stability === "drifting" || o.dataDepth === "thin" || dialectMismatch;
  // §8.3: WARN if l1未実施 or l2 == undeclared or drifting or thin or dialect mismatch
  const warnUndeclared = f.l2.status === "undeclared";
  if (warn || warnUndeclared) {
    // ALLOW 条件 (l0 pass ∧ (n_delivered≥1 ∨ optin) ∧ l2≠mismatch) を満たし、かつ WARN 事由が l2_undeclared だけなら ALLOW
    const allowCore = f.l0.status === "pass" && (f.l1.n_delivered >= 1 || !!o.allowWithoutL1) && f.l2.status !== "mismatch";
    if (allowCore && !warn) return { recommendation: "ALLOW", reason_codes: r };
    return { recommendation: "WARN", reason_codes: r };
  }
  return { recommendation: "ALLOW", reason_codes: r };
}
```
**注**: §8.3 は「WARN if … l2 == undeclared」と「ALLOW if l0 pass ∧ L1配達 ∧ l2 ≠ mismatch」を同時に書いており、宣言の無い店（本番の大多数）が全て WARN になる読みは §9.1 の例（`reason_codes: ["l0_pass","l1_delivered","l2_undeclared"]` が ALLOW の例として置かれている）と矛盾する。**採用**: `l2_undeclared` は reason_code に必ず載せ、**それ単独では ALLOW を妨げない**（他の WARN 事由があれば WARN）。この解釈は `docs/ethonline-2026/SPEC_1_2_IMPACT.md` §5 に追記して開示する。上のコードの `warn` 式から `&& false` の項は消して整理する。

```ts
export type PayeeOptions = { now: Date; operatorBlacklist?: boolean };
export function decidePayee(f: BuyerFacts, o: PayeeOptions): { recommendation: Recommendation; reason_codes: string[] } {
  const r: string[] = [];
  const degraded = f.sybil.unavailable.length > 0;
  const sybilHigh = f.sybil.multi_agent_owner && f.sybil.shared_funder;
  const burst = f.retry_burst_rate !== null && f.retry_burst_rate > RETRY_BURST_BLOCK;
  const ageDays = f.first_seen ? (o.now.getTime() - Date.parse(f.first_seen)) / 86_400_000 : null;
  if (o.operatorBlacklist) r.push("operator_blacklist");
  if (sybilHigh) r.push("sybil_high");
  if (burst) r.push("retry_burst");
  if (degraded) r.push(...f.sybil.unavailable.map((u) => `${u}_unavailable`));
  if (o.operatorBlacklist || sybilHigh || burst || degraded) return { recommendation: "BLOCK", reason_codes: r };
  if (f.settled_count_30d <= THIN_HISTORY_MAX) r.push("thin_history");
  if (f.sybil.shared_funder) r.push("shared_funder");
  if (ageDays !== null && ageDays < NEW_PAYER_DAYS) r.push("new_payer");
  if (r.length > 0) return { recommendation: "WARN", reason_codes: r };
  return { recommendation: "ALLOW", reason_codes: ["history_ok"] };
}
```
