## Carried in from before the event

### 1. The central sentence (2026-09-14 19:35)

> 証明する人（vet402）がいなくても、名前に置いた証明だけでエージェントは払える。約束が変われば、その証明ではもう払えない。

In English: even while the one who proves it (vet402) cannot be reached, an agent can pay on the proof
stored in the name alone. Once the promise changes, that proof no longer pays.

With it, a rule for every English version: "cannot be reached" means "even while vet402's API is
unreachable", never "without vet402". The agent still asks vet402 every time; only when no answer comes
back, and the proof meets the floor the caller declared, does it pay.

### 2. The three quality axes, not to be cut (approved before the event)

1. **One record carries the whole promise.** Price, payee and URL sit in one value, `x402-offer`, and that record is attested with ENSIP-29. One character changed anywhere, and the attestation fails.
2. **The contrast a judge remembers.** With vet402's API unreachable, the agent pays; change one character of the promise, and the same call refuses. The agent asks and gets no answer; it does not skip asking.
3. **Sign as the draft says, read both forms.** Signing follows the ENSIP-29 draft text; the check reads both the draft's form and the reference implementation's form.

- Landed in: (1) `packages/sdk/src/atst-codec.ts`, `packages/sdk/src/ens-attestation.ts`; (2) scene 2, recorded 2026-09-26 09:29 to 09:36 (Sepolia blocks 11782719 and 11782723); (3) `packages/sdk/src/atst-codec.ts`
