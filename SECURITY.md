# Security Policy

## Reporting a vulnerability

Do not open a public issue for vulnerabilities in the purchase or scoring path.

- Scope, rules of engagement and what counts as a finding are in
  [`docs/PENTEST_SCOPE.md`](./docs/PENTEST_SCOPE.md).
- Contact the operator through the site, [vet402.com](https://vet402.com), with the
  finding and a way to reproduce it. Anything that could move funds or expose a
  production secret should be reported immediately on discovery, not batched.

This is the same policy as the "Reporting security issues" section of
[`CONTRIBUTING.md`](./CONTRIBUTING.md); this file exists so GitHub surfaces it in the
repository's Security tab.
